# Matt's Task List for 418Y
Author: Matt Lawrence

## Description

Matt's Task List for 418Y is a small interactive web page for adding, completing, deleting, and timestamping tasks that a user assigns and sets a priority to that task.

## How to Run

double click `index.html` in a web browser.

## Known Problems or Incomplete Features

Tasks are stored only while the page is open. They disappear when the page is refreshed.
